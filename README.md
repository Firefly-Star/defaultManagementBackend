# Default Management Backend

A Spring Boot backend for a restaurant management system, providing RESTful APIs for order processing, menu management, and user administration.

## Tech Stack

- Java
- Spring Boot
- MyBatis
- MySQL
- Maven

## Build & Run

```bash
./mvnw spring-boot:run
```

## Features

- Order management API
- Menu and product management
- User authentication and authorization
- Database persistence with MyBatis
